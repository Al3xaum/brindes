☁️ Armazenamento de Fotos (Supabase) ▼

Ao enviar uma foto, ela é otimizada e salva no Supabase Storage (bucket brindes).

Configuração no Supabase:

  1. Acesse o painel do Supabase.
  2. Clique em Storage > New bucket.
  3. Nome: brindes (marque Public bucket).

* Dica: Se o bucket ainda não estiver criado, a foto é automaticamente salva comprimida no banco de dados para você nunca travar!
